# Support Guide

If you need help or have questions about running the reinforcement learning portfolio, please check the following resources:

## 1. Getting Started Guide
First, make sure you have read the [GETTING_STARTED.md](GETTING_STARTED.md) file. It contains step-by-step instructions on setting up environments and runs, and addresses common troubleshooting issues (such as dependency errors or stuck training).

## 2. Concepts Reference
If you need clarification on reinforcement learning algorithms, how they connect, or the math behind them, refer to the [CONCEPTS.md](CONCEPTS.md) file.

## 3. GitHub Discussions
For general questions, design feedback, and showing off what you've built, we encourage using **GitHub Discussions** in our repository. This is the best place to ask questions like:
*   "Why is my SAC agent not converging on Lunar Lander?"
*   "How can I integrate Weights & Biases with IPPO?"
*   "What hyperparameters should I use for BESS optimization?"

## 4. Issues for Bugs and Features
*   If you find a confirmed bug in the codebase, please open a bug report using our [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md).
*   If you want to suggest new algorithms or feature additions, use our [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.md).
