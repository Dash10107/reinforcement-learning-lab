# Green Logistics (DQN Project)

This project is covered in **[Chapter 5 — When the Maze Gets Too Big](../dqn/)**.

The Green Logistics environment is one of two DQN projects in this course. An agent routes delivery trucks through a city grid, minimising fuel cost and delivery time using a Deep Q-Network trained on a visual grid representation.
