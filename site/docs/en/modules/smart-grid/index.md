# Smart Grid Energy (DQN Project)
<br> *Applying DQN to dynamic prices.*

This project is covered in **[Chapter 5 — When the Maze Gets Too Big](../dqn/)**.

The Smart Grid environment challenges a DQN agent to manage a 24-hour electricity market — deciding when to buy, store, and sell energy to minimise cost while meeting demand. The reward function captures economic efficiency and grid stability.
